# Page Stats

หน้ารายงานสถิติคลิปสั้นรายวันของสองช่อง เปิดดูได้ที่ GitHub Pages ของ repo นี้

| ช่อง | โฟลเดอร์ข้อมูล | repo ที่เก็บสถิติ |
|---|---|---|
| ต่างกันยังไง | `data/diff/` | `whats-difference-poster` |
| The Muscle Manual | `data/mm/` | `muscle-poster` |

## ข้อมูลมาจากไหน

repo นี้**ไม่ได้**เก็บสถิติเอง และไม่มี token ใด ๆ อยู่ในนี้

ตัวเก็บอยู่ใน repo ส่วนตัวของแต่ละช่อง (`stats/collect.py` + workflow `stats.yml`) รันทุกคืน
อ่าน `jobs/*.json` ที่บันทึก remote id ของคลิปที่ปล่อยไปแล้ว ยิง API ของ YouTube / Meta / Buffer
แล้ว push ผลลัพธ์กลับมาที่ repo นี้

## รูปแบบไฟล์

- `data/<ช่อง>/snapshot-<วันที่>.json` — ข้อมูลเต็มของวันนั้น มีรายคลิปครบ
- `data/<ช่อง>/trend.json` — สรุปย่อวันละบรรทัด ไม่มีรายคลิป

หน้าเว็บโหลด `trend.json` ก่อนเพื่อวาดกราฟกับตั้งช่วงวันที่ แล้วค่อยโหลด snapshot เต็ม
เฉพาะวันที่เลือก ไฟล์รายวันจึงสะสมได้โดยไม่ทำให้หน้าช้าลง

## แก้หน้าเว็บ

ต้นฉบับอยู่ที่ `pagestats/web/index.html` บนเครื่อง เป็นไฟล์เดียวจบ ไม่มีขั้นตอน build
แก้แล้ว push ทับได้เลย
